# Soft Contact

The prompt brief is muted, rounded close contacts with supple rubber and fine surface texture. It preserves each physical material and
recognizable small urethane skateboard wheels and a wooden deck.

This complete bank contains 53 distinct mono 48 kHz PCM16 WAVs (2,924,572 bytes):
four contacts for each of seven footstep pools, eight surface rolling loops,
two landings per skate surface and one powerslide loop. Contacts are individual
plant/landing events; no walking rhythm is baked into runtime playback.

Sources were selected from 45 local Small-SFX raw takes using the unchanged
production contact/loop extractor. Selection prefers distinct raw takes, then
longer valid isolated contacts. Every footstep and landing pool uses at least two
actual raw takes. Rejected and unselected candidates remain authoring evidence;
no acceptance threshold, playback gain or extracted PCM was changed to fill a role.

Each manifest entry records the actual prompt, seed, pinned model/source/weight
revisions, sampler, raw checksum, processor checksum, exact source interval and
loop crossfade. The committed WAV is the verified extractor output. The model is
an offline authoring dependency; normal builds need only these committed assets.

The existing material mapping sends Tatami to `barefoot`, dirt/gravel to
`dirt_gravel` and wet mud to `mud_water`. Other declared cue families explicitly
inherit Original, including hoof stand-ins, bikes, combat, ambience/voices, UI
and unrelated skate cues. Original remains the default.

Structural and signal validation establish complete source coverage, not
subjective listening acceptance or new native/cooked gameplay evidence. The bank
uses the existing registry, selector and normal preparation/import/stage/cook graph.
