# Haras Valley

A game in preparation. Nothing runs yet: there is no `game.toml`, build recipe or Unreal project. The folder holds the
assets made ahead of the game, starting with its first character in `assets/characters/`.

When the game starts, `atelier new` makes the game skeleton from the sandbox; the assets here are then wired into its
`game.toml` and `build.py` the way Yorimichi wires Cairo (`games/yorimichi/game.toml`, `characters.cairo`).
